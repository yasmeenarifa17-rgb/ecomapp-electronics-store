A full-stack E-Commerce web application built using React, Node.js, and Express.
LIVE WEBSITE : https://ecomapp-electronics-store.vercel.app/

## Features

- Product Catalog
- Add to Cart
- Cart Total Calculation
- User Signup & Login
- Admin Dashboard
- Role-Based Access
- Responsive UI
- Backend API Integration

## Technologies Used

### Frontend
- React.js
- React Router DOM
- Axios

### Backend
- Node.js
- Express.js

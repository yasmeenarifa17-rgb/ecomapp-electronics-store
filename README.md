# EcomApp - Electronics Store

A full-stack E-Commerce web application built using React, Node.js, and Express.

## Features

- Product Catalog
- Add to Cart
- Cart Total Calculation
- User Signup & Login
- Admin Dashboard
- Role-Based Access
- Responsive UI
- Backend API Integration

## Technologies Used

### Frontend
- React.js
- React Router DOM
- Axios

### Backend
- Node.js
- Express.js
